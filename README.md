# Our Little Universe ♡

Website hadiah romantis responsif menggunakan HTML, CSS, dan JavaScript.

## Menjalankan
1. Buka folder ini di VS Code.
2. Buka `index.html` dengan Live Server, atau klik dua kali `index.html` untuk membukanya di browser.
3. Ubah teks surat dan pesan di `index.html` sesuai cerita kalian.
4. Tambahkan foto ke folder `images` dengan nama `memory-1.jpg`, `memory-2.jpg`, `memory-3.jpg`.

## Publikasi dengan GitHub Pages
1. Buat repository baru di GitHub, misalnya `our-little-universe`.
2. Untuk publikasi gratis melalui GitHub Pages, repository biasanya perlu dibuat **Public** pada akun/plan yang mendukung Pages untuk repository publik.
3. Unggah `index.html`, `style.css`, `script.js`, dan folder `images` ke root repository.
4. Buka **Settings → Pages**.
5. Di **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main`, folder `/(root)`, lalu tekan **Save**.
7. Tunggu beberapa menit dan buka URL yang ditampilkan pada halaman Pages.

## Catatan
- Tombol musik di template ini hanya memberi petunjuk; belum memutar audio. Jika ingin menambahkan musik, gunakan file audio yang kamu miliki hak untuk menggunakannya dan tambahkan kontrol audio.
- Google Fonts memerlukan internet; jika offline, website menggunakan font fallback.
- Jangan menaruh informasi pribadi sensitif di website publik.
